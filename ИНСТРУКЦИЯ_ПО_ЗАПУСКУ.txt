1. СУТЬ И АРХИТЕКТУРА РАБОТЫ:
--------------------------------------------------------------------------------
Лабораторная работа посвящена исследованию архитектуры глобальных добровольных
распределенных вычислений (Volunteer Computing) на платформе BOINC (Berkeley Open
Infrastructure for Network Computing).
В проекте реализован программный аналитический комплекс на Python (boinc_calculations.py),
выполняющий моделирование грид-узлов:
1. Расчет кредитов Cobblestone (официальная метрика BOINC):
   100 кредитов начисляется за одни сутки работы процессора производительностью
   в 1 GFLOPS (или 1000 MIPS).
   Формула: Credit = (GFLOPS * T_sec * 100) / 86400
2. Моделирование времени обработки расчетных пакетов Work Units (WU) для реальных
   научных проектов (Rosetta@home, Einstein@Home, PrimeGrid).
3. Расчет сетевого входящего/исходящего трафика при передаче пакетов задач и результатов.
4. Оценка требуемого дискового буфера для непрерывной автономной работы узла
   при отсутствии постоянного сетевого подключения.
5. Сравнительный анализ производительности CPU (Intel Core i3, Core i5)
   и GPU (NVIDIA GeForce RTX 3050 CUDA).

4. ТИПОВЫЕ ВОПРОСЫ ПРЕПОДАВАТЕЛЯ (В. И. СТЕПАКОВА) И ОТВЕТЫ:
--------------------------------------------------------------------------------
В: Что такое Work Unit (WU) и Result в терминологии BOINC?
О: Work Unit — это порция исходных данных для вычисления задачи (например, параметры
   свертки белка или отрезок радиосигнала радиотелескопа). Result (или Instance) —
   это конкретный экземпляр задачи, отправляемый на конкретный клиентский хост,
   включающий возвращаемый файл результата.

В: Зачем в BOINC применяется избыточное вычисление (Redundant Computing)?
О: Так как вычисления выполняются на ненадежных и недоверенных пользовательских
   компьютерах, проект отсылает один и тот же Work Unit минимум двум разным
   пользователям (Quorum = 2). Затем валидатор сравнивает результаты (Bit-exact
   или с заданной погрешностью). Это исключает фальсификацию кредитов и ошибки
   аппаратного сбоя/разгона памяти.

В: В чем преимущество GPU перед CPU в грид-вычислениях?
О: GPU обладает тысячами вычислительных ядер (CUDA Cores) и высокой пропускной
   способностью памяти, выполняя модель вычислений SIMD/SIMT. Для задач
   математического моделирования и спектрального анализа (FFT) GPU дает ускорение
   в десятки раз по сравнению с классическими универсальными ядрами CPU.
