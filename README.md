# Лабораторная работа №3: Принципы организации грид-систем на платформе BOINC

**Дисциплина**: Параллельное программирование (Распределенное программирование)  
**Авторы**: Эрденко М. Д., Разгуляев Е. О. (группа ПО-32б, ЮЗГУ)  
**Преподаватель**: Ефремова И. Н.

## Описание
Исследование принципов организации грид-систем и добровольных распределенных вычислений на платформе BOINC (Berkeley Open Infrastructure for Network Computing).

## Состав репозитория
- `boinc_calculations.py` — расчет сетевого трафика, времени вычислений, затрат памяти, диска и начисления очков Cobblestone.

## Запуск расчетов
```bash
python3 boinc_calculations.py
```
