# Лабораторная работа №3: Принципы организации грид-систем на платформе BOINC

**Дисциплина**: Параллельное программирование (Распределенное программирование)

**Проверяющий**: В. И. Степаков

## Описание работы
Исследование принципов организации грид-систем и добровольных распределенных вычислений (Volunteer Computing) на платформе BOINC (Berkeley Open Infrastructure for Network Computing).

Работа включает:
1. Аналитическое моделирование начисления очков Cobblestone Credits в зависимости от вычислительной мощности узла (CPU/GPU) и времени работы.
2. Расчет времени выполнения вычислительных заданий (Work Units) для реальных распределенных проектов (Rosetta@home, Einstein@Home, PrimeGrid).
3. Оценку сетевой нагрузки (входящий/исходящий трафик) и требований к дисковой памяти для буферизации задач на узлах-добровольцах.
4. Исследование механизмов защиты от фальсификации результатов вычислений (Redundant Computing, Homogeneous Redundancy).

## Состав файлов
- `boinc_calculations.py` — расчет сетевого трафика, времени вычислений, емкости накопителя и начисления очков Cobblestone.
- `capture_boinc.py` — утилита мониторинга состояния локального клиента BOINC.
- `gui_rpc_auth.cfg` — конфигурационный токен авторизации для RPC интерфейса.
- `.vscode/` — конфигурационные файлы для разработки в Visual Studio Code (`tasks.json`, `launch.json`, `settings.json`).

## Запуск расчетов
```bash
python boinc_calculations.py
```
